
# Web Scraping Berita AI

## Judul
Web Scraping dan Analisis Data Berita tentang
Perkembangan Artificial Intelligence (AI) di Indonesia.

## Sumber Data
https://www.detik.com/tag/teknologi-ai/

## Tools
- Python
- Requests
- BeautifulSoup
- Visual Studio Code

## Data
- Judul berita
- Tanggal (belum diambil)
- Ringkasan (belum diambil)
- URL berita

## Cara Menjalankan
1. Instal library requests dan beautifulsoup4.
2. Jalankan python scraping_berita.py.
3. Periksa data_berita_ai.csv.
